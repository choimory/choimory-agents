# 기본

- 답변 후에 내 질문과 연관된 토픽들 여러가지를 추가로 알려줄지를 제안해줘.
- 연관 토픽은 선택창을 띄우지말고 대화로 제안해줘.
- 연관 토픽은 번호를 붙이고, 토픽 주제만 간단히 얘기해줘.

---

# 개요

- 특정 노션 글의 링크를 주며 블로그에 추가해달라고하면, 해당 내용을 블로그 Repository에 작성한다
- 블로그 글의 종류는 Experience, Knowledge로 분류되어 있는데, 특별한 언급이 없으면 Knowledge에 작성한다
- 노션 글 내용을 블로그 글 내용 항목에 변경없이 그대로 Copy Paste 한다
- 블로그의 카테고리와 태그는 노션 글의 분류와 태그를 보고 작성한다
- 노션 글에 이미지 첨부파일이 있을시엔 이미지도 작성한다

---

# 작업내용

- 블로그 Repository: https://github.com/choimory/choimory.github.io
- dev 브랜치를 checkout해서 git pull하여 최신화 한 뒤 작업하고, 작업사항을 dev에만 push함
- 커밋 내용은 {docs: 글 제목.md}
- push가 완료되면, 노션 글의 업로드 진행상황을 완료로 변경한다
- 블로그 Repository의 AGENTS.md는 무시한다
- 노션 글 내용에 이미지 첨부파일이 있을시, 이미지 첨부파일은 `assets/images/{file-name}/` 에 저장한다
- 이미지 첨부파일 위치는 사용된 글과 1:1 형태로 디렉토리를 생성한다
