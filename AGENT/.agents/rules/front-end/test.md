# 프론트엔드 테스트 규칙

- 기본 개발이 마무리 되면, 작성한 코드들의 테스트 코드 작성을 시작한다
- 작성한 테스트 코드들을 이용하여, 개발한 내용에 대한 검증을 진행한다
- ESLint로 구문 오류, 타입 에러, 코딩 컨벤션 등에 대한 정적 테스트를 진행한다
- Vitest로 테스트 코드를 작성하여 커스텀 훅, 함수, 유틸 등에 대한 단위 테스트를 진행한다
- React Testing Library로 컴포넌트에 대한 테스트 코드를 작성하여, 컴포넌트 테스트를 진행한다
- React Testing Library에 MSW (Mock Service Worker)로 API를 모킹한 테스트 코드를 작성하여 통합 테스트를 진행한다
- Playwright로 E2E 테스트를 진행한다
