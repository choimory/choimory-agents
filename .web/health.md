- 태그 필드는 기존 태그를 억지로 사용하지 말고, 태그를 새로 만들어도 되니 내용에 맞는 태그로 적절하게 적어줘.
- 내 질문과 토픽 제안은 내용에 포함하지 말고, 그 외의 내용은 반드시 답변 내용을 원문 그대로 적어줘.
- 내 질문 없이 답변 내용을 원문 그대로 적기가 어려울때는, 가상의 질문을 만들어서 적어줘.
- 노션 DB에 같은 주제의 기존 글이 있더라도, 기존 글은 건드리지 말고 새로 적어줘.
- 한 채팅 세션 내에 여러 개의 답변이 있을땐, 기본적으로 한 페이지에 답변들을 `--`로 구분해가며 내용 그대로 append하는 형태를 선호하지만, 너무 길다 싶을때는 답변별로 페이지를 만들어서 나눠서 써주는 것도 고려 가능.
- 노션에 적을 답변이 하나여도, 본문에 제목(h1)도 같이 적어줘.
- 노션 작성 후, 만들어진 노션 페이지 URL 알려줘.
